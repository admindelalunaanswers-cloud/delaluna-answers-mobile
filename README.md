# delaluna-answers-mobile

An [Expo](https://expo.dev) mobile app for Android and iOS, built with [Expo Router](https://docs.expo.dev/router/introduction).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

   Then press `a` for Android emulator or `i` for iOS simulator.

## Development

- Edit files inside the **app** directory — the project uses [file-based routing](https://docs.expo.dev/router/introduction)
- Press `cmd + d` (iOS) or `cmd + m` (Android) to open developer tools

## Fresh start

```bash
npm run reset-project
```

Moves the starter code to **app-example** and creates a blank **app** directory.
